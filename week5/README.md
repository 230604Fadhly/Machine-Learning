## 📌 Deskripsi

Project ini mengimplementasikan metode **Supervised Learning (Classification)** menggunakan dataset Iris untuk mengklasifikasikan jenis bunga berdasarkan fitur numerik.

---

## 📂 Dataset

**File:** `Iris.csv`

### Fitur:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

### Target:

* Species (Setosa, Versicolor, Virginica)

---

## ⚙️ Teknologi & Library

* Python
* pandas
* numpy
* matplotlib
* seaborn
* scikit-learn

---

## 🔍 Metodologi

### 1. Data Preparation

* Load dataset menggunakan pandas
* Cek missing values
* Split fitur dan target

### 2. Exploratory Data Analysis (EDA)

* Visualisasi distribusi data
* Pairplot antar fitur
* Heatmap korelasi

### 3. Data Splitting

* Training Data: 70%
* Testing Data: 30%

### 4. Model Training

* Menggunakan model classification (scikit-learn)

### 5. Evaluasi Model

* Accuracy Score
* Confusion Matrix
* Classification Report
